# Documentation

Matchstick Sanguo documentation lives in this directory. `AGENTS.md`
intentionally remains at the repository root because development tools discover
project instructions there.

- [Sanguo design](SANGUO-DESIGN.md) — campaign and real-time battle design contract
- [Sanguo art](SANGUO-ART.md) — sketch style and visual system
- [Unit reference](UNITS.md) — unit roles, statistics, counters, and default composition
- [Progress](PROGRESS.md) — implementation status and verification history
- [Issues](ISSUES.md) — open defects and decisions
- [Fonts](FONTS.md) — brush-kai subset, licence, and rebuild workflow

The Outbreak, Cannae, and The Hold are archived under the
[`reference/`](../reference/README.md) tree with their own pages, scenario
packs, designs, and regression tests.
